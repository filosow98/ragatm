# Chunking strategy

In the chunking implementation, I had to make chunks of size up to the max
  character count. Chunks could not be too small so that they had meaningful
  number of words for the retrival algorithm. Bigger chunks can hold, to a
  certain extent, some semantic information through the word frequency.

   The text
  could be ethier a text file of a python code, so the chunking algorithm should
  take into consideration the syntax of each formats to better preserve the
  meaning of the text in individual chunks.
